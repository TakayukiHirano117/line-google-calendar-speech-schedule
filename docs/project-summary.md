# ぶいつー プロジェクト概要

## これなに？

LINEに音声メッセージを送るだけで、Googleカレンダーに予定を自動登録してくれるLINE BOT。

「明日の14時から会議ね」と話しかけるだけでOK。AIが内容を理解してカレンダーに登録してくれるので、スマホをぽちぽちする手間がなくなる。

---

## できること

| 機能 | 操作方法 |
|------|----------|
| 音声で予定を登録する | 音声メッセージを送るだけ |
| 登録した予定を確認・編集・削除する | LINEのメニューから操作 |
| 今日の予定を確認する | 「今日の予定」と送信 |
| 今週の予定を確認する | 「今週の予定」と送信 |
| Googleアカウントとの連携を解除する | 「ログアウト」と送信 |

---

## 音声→予定登録の仕組み

1. LINEで音声メッセージを送信
2. **Google Cloud Speech-to-Text** が音声をテキストに変換
3. **Gemini（Google AI）** がテキストから「日時」「タイトル」などの予定情報を抽出
4. **Google Calendar API** でユーザーのカレンダーに予定を登録
5. LINEに完了メッセージが届く

---

## 使っている主な技術

| 役割 | 技術・サービス |
|------|---------------|
| アプリの動作基盤 | Google Apps Script（GASと呼ばれるGoogleのサーバー実行環境） |
| LINEとの連携 | LINE Messaging API |
| 音声認識 | Google Cloud Speech-to-Text API |
| AI（予定情報の抽出） | Gemini 2.5 Flash Lite |
| カレンダー操作 | Google Calendar API |
| ユーザー認証 | OAuth2（GoogleアカウントとLINEを安全に連携する仕組み） |
